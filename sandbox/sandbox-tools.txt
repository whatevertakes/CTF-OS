CTF-OS SANDBOX CAPABILITIES

Base: file/binutils, gdb/strace/ltrace, curl/nc/socat, gcc/g++, Python,
pwntools, pycryptodome, sympy, z3, capstone, unicorn, ROPgadget, requests.

Optional build targets add rev, crypto, or forensic-heavy packages. Build only
the profile a challenge needs. Nested container engines and Codex are absent.

Challenge input is mounted read-only at /challenge. /work and /artifacts are
attempt-private, size-bounded tmpfs mounts. Files in /artifacts are safely
exported to the selected branch after each internal sandbox command.
